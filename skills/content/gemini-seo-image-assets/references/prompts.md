# Prompt Templates

Use these as starting points. Replace the product nouns, palette, and mood with project-specific language.

## 1. Favicon Source

```text
Use case: stylized-concept
Asset type: website favicon source artwork
Primary request: Create a square, minimal emblem for <project or brand>.
Scene/backdrop: <paper / texture / atmospheric surface>.
Subject: one centered abstract mark suggesting <core project metaphor>.
Style/medium: refined editorial image, icon-ready, not photorealistic.
Composition/framing: perfect 1:1 square, centered subject, large negative space, silhouette legible at 16px.
Lighting/mood: restrained, still, intentional.
Color palette: use only <project palette>.
Text (verbatim): none.
Constraints: no letters, no words, no border, no watermark, no extra objects.
Avoid: clutter, tiny details, bright accents, glossy effects.
```

## 2. OG Background

```text
Use case: stylized-concept
Asset type: open graph social preview background
Primary request: Create a wide atmospheric cover image for <project or brand>.
Scene/backdrop: <surface, fibers, grain, or environmental metaphor>.
Subject: an abstract composition suggesting <project theme>.
Style/medium: fine-art editorial cover, not photorealistic.
Composition/framing: wide horizontal 16:9, reserve one side as calm negative space for title overlay.
Lighting/mood: <time of day>, restrained, contemplative.
Color palette: use only <project palette>.
Text (verbatim): none.
Constraints: no visible letters, no signage, no people unless the product requires them, no watermark.
Avoid: busy scenes, decorative overload, saturated color, glossy UI effects.
```

## 3. Overlay Policy

Never ask Gemini to render the final title block if the copy must be exact.

Preferred split:

- Gemini: composition, atmosphere, texture, symbolic forms.
- Local code: title, subtitle, tagline, exact logo text, export sizes.
